Machine Learning :

A Machine Learning project implementing supervised model with  9 different algorithms with 9 datasets, including classification and regression models. Each model predicts results, evaluates performance, and generates graphical visualizations.

Models Used:
  1)Naive Bayes – Iris
  2)SVM – Breast Cancer
  3)KNN – Wine
  4)Decision Tree – Diabetes
  5)Random Forest – California Housing
  6)Linear Regression – Titanic
  7)Logistic Regression – Heart Disease
  8)Lasso Regression – Student Performance
  9)Ridge Regression – Mall Customers

Technologies:
    Python
    Pandas
    NumPy
    Matplotlib
    Seaborn
    Scikit-learn
    Google Colab
